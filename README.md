# Prumo Med — Landing Page Oficial

Landing page moderna e de alta conversão para a **Prumo Med**, clínica especializada em **Tratamento para Dores na Coluna, Nervos e Crânio** em Goiânia - GO.

O design segue a linguagem visual **Nordic / Swiss High-End Medical Editorial**, inspirada em estúdios médicos contemporâneos com minimalismo funcional, tipografia geométrica precisa (Geist), paleta em tons profundos de azul petróleo (*deep teal*) e menta gelo (*ice mint*), além de microinterações fluidas.

## 🚀 Como Executar Localmente

### 1. Clonar o repositório
```bash
git clone https://github.com/MendesLife/Prumo-Med.git
cd Prumo-Med
```

### 2. Instalar as dependências
```bash
npm install
```

### 3. Rodar em ambiente de desenvolvimento
```bash
npm run dev
```

### 4. Gerar build de produção
```bash
npm run build
```

### 5. Pré-visualizar o build localmente
```bash
npm run preview
```
